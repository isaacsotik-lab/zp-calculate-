# Проверка

Синтетические справки 2-НДФЛ (все данные вымышлены) и автотест.

- `gen.py` — создаёт справки и `expected.json` с ожидаемыми результатами, посчитанными независимо от сайта.
- `e2e.py` — открывает сайт в браузере (Playwright, Chromium), загружает справки и сверяет результат, плюс календарь, НДФЛ, даты выплат, профили, резервную копию и вёрстку на 320–768 px.

Сценарии: A — Госуслуги (.zip, смена работы, справка СФР), B — только PDF, C — уточнённая справка, D — несколько справок в одном XML, E — доход выше 2,4 млн, F — ошибки (скан, архив без справки, чужой файл).

Запуск: `python3 tests/gen.py && python3 tests/e2e.py`
