# Калькулятор зарплаты

Личный калькулятор зарплаты на руки: аванс, остаток, отпускные, больничные, НДФЛ за год.
Работает в браузере телефона, данные хранятся только на устройстве.

**Открыть:** https://isaacsotik-lab.github.io/zp-calculate-/

## Как начать (для близких)

1. Откройте ссылку в Safari на iPhone.
2. Нажмите «Поделиться» → «На экран „Домой“» — появится иконка ₽, калькулятор будет открываться как приложение.
3. Введите оклад до вычета налога и нажмите «Готово». Этого достаточно для расчёта.
4. Для точных цифр загрузите справки 2-НДФЛ (внизу, «Справки 2-НДФЛ»):
   - Госуслуги → поиск «Справка о доходах» → выберите год → «Скачать» (сохранится .zip в «Файлах»);
   - нужны справки за текущий год и два прошлых; если менялась работа — от каждого работодателя;
   - подходят .zip с Госуслуг, .xml из кабинета налоговой и PDF от бухгалтерии. Сканы и фото не читаются.
5. В табеле отмечайте дни: «Не работал», «Отпуск», «Больничный», «Работа в выходной».

Если одним телефоном пользуются несколько человек — «Профили семьи» внизу страницы.
Чтобы перенести данные на другой телефон — «Резервная копия» → «Скопировать код», на новом телефоне «Вставить из буфера и восстановить».

## Что считается

- Зарплата пропорционально отработанным дням по производственному календарю РФ (2026, 2027 с переносами).
- Аванс: за дни 1–15, процент оклада или фиксированная сумма — отдельно для каждого месяца.
- НДФЛ по прогрессивной шкале 13–22 % нарастающим итогом, вычеты на детей.
- Отпускные по среднему заработку, больничный по стажу с лимитом и минимумом по МРОТ.
- Даты выплат с переносом на предыдущий рабочий день.
- Справки 2-НДФЛ: фактический доход по месяцам, средний заработок для отпуска и больничного, подсказка оклада.

Расчёт ориентировочный: точные суммы — в расчётном листке и у бухгалтерии.

## Приватность

Страница ничего не отправляет в интернет (Content-Security-Policy запрещает внешние запросы).
Справки разбираются на телефоне; ФИО, ИНН и паспортные данные не сохраняются.

## Файлы

- `index.html` — всё приложение.
- `sw.js`, `manifest.webmanifest`, `icon-*.png` — работа как приложение и без интернета.
- `lib/pdf.js`, `lib/pdf.worker.js` — [pdf.js](https://github.com/mozilla/pdf.js) 3.11.174 (Apache-2.0) для чтения PDF; загружается только при выборе PDF.
